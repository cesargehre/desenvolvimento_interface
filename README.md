# Desenvolvimento de Interface

Repositório utilizado para registrar atividades e projetos da disciplina **Desenvolvimento de Interface**, com práticas de HTML, CSS e JavaScript.

## Conteúdo

- **`HTML/`** — primeiro exemplo de página HTML com estrutura e apresentação de conteúdo.
- **`Java/`** — exercícios introdutórios de JavaScript e material de apoio da disciplina. Apesar do nome da pasta, os exercícios são escritos em JavaScript.
- **`calculadora-de-media/`** — calculadora de média em HTML, CSS e JavaScript, com registro de testes.
- **`projeto java/`** — projeto inicial de uma calculadora em JavaScript.
- **`projeto java2/`** — exercício com HTML e JavaScript para interação entre páginas e scripts.
- **`projeto java 3/`** — versão de uma calculadora de média, incluindo uma captura da interface.
- **`index.html`** — página principal do repositório, preparada para ser visualizada no navegador.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como visualizar os projetos

Os projetos podem ser abertos diretamente no navegador. Para a página principal, abra o arquivo `index.html` na raiz do repositório.

Caso utilize o **Visual Studio Code**, o [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) permite executar os arquivos HTML com um servidor local.

Os exercícios JavaScript da pasta `Java/` também podem ser executados com Node.js:

```bash
node "Java/Lista de exercícios"
```

## Objetivo

Organizar e acompanhar a evolução dos estudos em desenvolvimento web, praticando fundamentos de estruturação de páginas, estilização e programação no navegador.
