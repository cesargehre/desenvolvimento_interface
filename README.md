# Desenvolvimento de Interface

Esta pasta reúne atividades e materiais produzidos nas aulas de **Desenvolvimento de Interface**, com foco introdutório em **JavaScript**. Os exercícios praticam conceitos fundamentais da linguagem e sua relação com páginas web.

> **Observação:** embora a pasta se chame `Java`, o conteúdo disponível nela é de JavaScript.

## Conteúdo

- **`Lista de exercícios`** — resolução de 16 exercícios sobre saída no console, variáveis, tipos de dados, operadores, cálculos, descontos, médias e expressões lógicas.
- **`Material_Estudante_JavaScript_Aula01_CEUB.md`** — material de apoio da aula sobre introdução ao JavaScript, variáveis, tipos de dados e operadores. Também apresenta atividades práticas, incluindo uma calculadora e um desafio de cálculo de média.
- **`Material`** — arquivo reservado para materiais adicionais.

## Conceitos praticados

- Declaração e atualização de variáveis com `let` e `const`;
- Tipos de dados e uso de `typeof`;
- Operadores aritméticos, de atribuição, comparação e lógicos;
- Cálculo de compras, descontos e médias;
- Exibição de resultados com `console.log()`.

## Como executar os exercícios

A lista contém código JavaScript que pode ser executado com Node.js. No terminal, dentro desta pasta, use:

```bash
node "Lista de exercícios"
```

Também é possível copiar trechos para o console do navegador. O material de apoio inclui exemplos de páginas HTML com CSS e JavaScript; para esses exemplos, abra o arquivo HTML correspondente em um navegador.

## Objetivo

Registrar e organizar os projetos da disciplina, praticando os fundamentos de JavaScript e o desenvolvimento de interfaces web de forma gradual.
